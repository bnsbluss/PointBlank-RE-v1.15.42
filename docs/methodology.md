# Research Methodology

## Core Principle

Understand first, verify second, experiment third.

```text
Observe
 ↓
Measure
 ↓
Map
 ↓
Hypothesize
 ↓
Verify
 ↓
Document
 ↓
Experiment
```

## Evidence Rule

An AI suggestion or analyst assumption is not sufficient evidence. Important conclusions should be supported by static analysis, runtime behavior, server source, logs, or another reproducible technical observation.

## Binary Handling

Keep the original executable unchanged. Perform analysis and experiments on copies.
